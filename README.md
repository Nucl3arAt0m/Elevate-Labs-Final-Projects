## Project 1: Web Application Vulnerability Scanner
- **Objective**: Detect XSS, SQLi, and CSRF vulnerabilities.
- **Features**:
  - Crawler for forms and URLs (`crawler.py`)
  - Vulnerability scanning with payloads and regex (`scanner.py`)
  - Flask UI for scan management (`app.py`, `templates/scan.html`)
  - Logging and reporting (`vulnerabilities.log`, `Web_app_vuln_Scanner_report.pdf`)
- **Outputs**: vulnerabilities.log, Web_app_vuln_Scanner_report.pdf
- **Screenshots**: See vuln_scanner/screenshots/
- **Report**: Web_app_vuln_Scanner_report.pdf
